# 实验结果：遮挡序判据的结构性失效（64 张实产卡审计）

> 运行环境：2 核 CPU / 无 GPU / onnxruntime 1.29.0；深度模型 Depth Anything V2 small int8（26MB）
> 数据：`generator/projects/` 下 65 个目录，剔除 1 个 `_preview`，**有效样本 64 张**
> 脚本：`generator/depth/probe_depth_failure.py`、`generator/depth/ablate_occlusion.py`
> 原始数据：`research/depth-study/data/depth_failure_probe.json`、`research/depth-study/data/occlusion_ablation.json`、`research/depth-study/data/atmosphere_batch.json`

## 一、真值的设计（为什么这套数据是可证伪的）

每张卡的 `background.png` 与 `subject.png` 是分别生成、再由管线合成的。合成时主体被固定放在最上层。
**因此「主体应当完整可见」是构造已知的真值，不是人工标注。**

推论：遮挡推断扣掉主体的任何一部分，都是**可证伪的假阳性**。阳性样本数在本设定下恒为 0。

## 二、主结果：现行判据在 61/64 张卡上会误裁主体

判据复述（`infer_occlusion.py`）：`d_s = median(depth[主体足迹])`，`前景 = depth > d_s + 0.15`，扣减主体。

| 指标 | 值 |
|---|---:|
| 平均误裁比例 | **25.9%** |
| 中位 | 27.4% |
| 最大 | 44.2%（shang-ji-zi） |
| 触发扣减（>5%）的卡 | **61 / 64** |
| 零误裁的卡 | 2（sayram-lake、vc-dockyard） |

按系列拆看，误裁率几乎无差异：殷商 26.3%（n=27）、哈兰德 25.2%（n=15）、GTA-VC 25.3%（n=15）。**这不是某一类题材的问题。**

**数据可复现性说明**：`spread`（主体足迹内 depth 的 p90−p10）此前只做了临时计算、未落盘，本轮已写入 `research/depth-study/data/depth_failure_probe.json` 的 `spread` / `d_p10` / `d_p90` 字段，上述相关可由数据直接复算，不依赖任何未保存的中间量。

## 三、机制：误裁率由背景纵深跨度决定，与纹理无关

**被证伪的假说（纹理诱导伪深度）**：原假设是生成式装饰纹理让深度模型「脑补」出地形起伏，进而误裁。实测不支持：

| 指标 | Spearman ρ vs 误裁率 | p |
|---|---:|---:|
| FRDG（平坦-纹理区深度梯度） | −0.175 | 0.17 |
| TRD_b（纹理区/平滑区伪起伏倍率） | −0.204 | 0.11 |
| texture_density（纹理能量） | −0.130 | 0.31 |
| 锐度比 | +0.106 | 0.41 |

**成立机制（纵深跨度）**：`spread = p90(depth[足迹]) − p10(depth[足迹])`

| 指标 | 值 |
|---|---:|
| Spearman(spread, 误裁率) | **+0.699（p = 1.3e−10）** |
| Pearson(spread, 误裁率) | **+0.761（p = 2.9e−13）** |
| spread 中位 / 范围 | 0.546 / 0.000–0.945 |

解释：`median` 不是平面模型。主体足迹覆盖了背景中一段真实的纵深梯度时（例如上方天空、下方地面），中位数只是一个折中点，而 `+0.15` 是绝对值阈值；凡是比折中点近 0.15 以上的背景，都被判成「挡住主体」。**跨度越大，被误判的面积越大。** 这与深度模型准不准无关——换更准的模型，跨度照样存在。

## 四、消融：30 种参数组合下没有一个是安全的

估计器 × 阈值 = 5 × 6 = 30 组配置。

| 判据 | 平均误裁% | 触发>5% 卡数 |
|---|---:|---:|
| median\|0.15（现行） | 25.9 | 61 / 64 |
| mean\|0.15 | 22.6 | 60 / 64 |
| p25\|0.15 | 40.0 | 62 / 64 |
| p75\|0.15 | 10.5 | 52 / 64 |
| plane\|0.15 | 9.3 | 43 / 64 |
| **plane\|0.30（全局最优）** | **1.9** | **9 / 64** |

- 能把全部 64 张压到 <0.5% 误裁的配置：**0 个**。
- 每张卡在 30 组里挑自己的最优解：中位误裁可降到 0.0%，但仍有 **5 / 64 张无论怎么调都压不到 5% 以下**。

结论：**判据的失效是结构性的，不是调参问题。** 平移到最优配置能压下均值，但压不平分布，且最优配置与产品所需的「不误裁」仍然隔着 9 张卡。

## 五、第二条独立发现：锐度倒挂

| 指标 | 值 |
|---|---:|
| 背景比主体更锐的卡 | **37 / 64** |
| 锐度比中位 | 1.13 |
| 极端案例 | shang-dark-bird 3.79、shang-yachou-yue 3.21、pouch-invader 2.71 |

背景锐度高于主体，意味着合成后视觉层级倒挂：本该退到后面的东西比主体更抢眼。这与遮挡推断无关，是独立的组装缺陷。

## 六、对照：唯一被实测证明有效的补救

深度驱动的**大气合成**（景深 + 自适应雾 + 光衰减，只改外观不动轮廓），在赛里木湖卡上把主体区/背景区的 Laplacian 对比度分离比从 **8.36 提升到 19.03（2.28×）**；亚丑钺卡 0.29 → 0.32（弱，纹理背景需另调参）。

即：**制造层级感应当靠「深度驱动的外观线索」，而不是「深度驱动的层序推断」。**

## 七、对论文含义的改写

| 项 | 原设想 | 实测后 |
|---|---|---|
| 核心主张 | 生成式图上单目深度会失效，且可无真值预测 | 预测方向被证伪（无信号）；但发现更强的结构性问题 |
| 证据规模 | 2 个案例 | 64 张实产卡 + 30 组消融 |
| 可证伪性 | 弱（无真值） | 强（真值由构造成立） |
| 定位 | 方法论文（新指标） | **审计/负结果论文（假设失效的实证）** |

新的论文骨架（三条被写进管线的假设，逐条实证）：

1. **假设一：层序可以从背景深度推断出来。** → 64 张卡平均误裁 25.9%，61/64 触发；30 组参数无安全解；根因是判据把深度场当标量阈值，误裁率与纵深跨度 ρ=+0.70。
2. **假设二：AI 生成的装饰纹理会让深度模型脑补地形，这是主要误差源。** → 证伪（ρ=−0.18，n.s.）。这直接否定「换更好的深度模型」这条补救路径。
3. **假设三：把层单独生成再叠起来，观感不受影响。** → 锐度倒挂 37/64，中位比 1.13。
4. **有效补救**：深度驱动大气合成，分离比 8.36 → 19.03。

## 八、局限（第一轮实验）

- 阳性样本恒为 0，**因此本实验只能测假阳性，测不出召回**。任何「修好了」的说法在本设定下都无法被验证——这本身就是结论的一部分。
- spread 与误裁率是相关关系，机制解释（中位数 vs 平面）有代码依据，但未做「用真实平面模型替代中位数后是否仍失败」的独立验证。
- 64 张卡均来自本仓库单一生产管线，风格分布集中（殷商 29 / 哈兰德 15 / VC 15 / 其他 5），外部有效性别说太满。
## 九、补测：大气合成的全库效果（64 张，替代原第 6 节的个案结论）

原第 6 节只有 2 张卡的个案，本补测把它扩到全库 64 张，并同时跑 σ_max = 12 与 30 两档。

**度量修正**：改用「合成完成后」的图来算，主体区（alpha>0.5 腐蚀）与背景区（alpha<0.05 腐蚀）的 Laplacian 标准差之比 SR = S_sub / S_bg。此前的 36/62（旧口径，62 张样本）「背景更锐」是在原始背景图与主体图分别算的，主体图透明区的 RGB 会污染 Laplacian，口径不干净；**以本节的 29/64 为准**。

| 指标 | 处理前 | σ12 后 | σ30 后 |
|---|---:|---:|---:|
| SR 中位 | 1.09 | **1.69** | 1.75 |
| SR 均值 | 1.34 | 2.50 | 2.67 |
| 倒挂卡（SR<1） | **29 / 64** | **14 / 64** | 13 / 64 |

- 改善的卡：**57 / 64**；变差的卡：**0**。ΔSR 中位 +0.39，最大 +7.76。
- σ_max 从 12 加到 30，额外改善中位仅 **+0.05**——**加大参数基本无效**。

**门控变量**：`far_mean` = 背景区「比对焦面远多少」的均值，即景深实际作用的强度。

| 关系 | Spearman ρ | p |
|---|---:|---:|
| far_mean vs ΔSR | **+0.532** | 6.1e−06 |
| far_mean vs SR_before | −0.070 | 0.59（不显著） |
| S_bg_before vs SR_before | **−0.890** | 4.4e−22 |

按 far 分档看中位 SR：

| far_mean | n | 处理前 | σ12 后 | ΔSR 中位 |
|---|---:|---:|---:|---:|
| <0.20 | 14 | 1.19 | 1.67 | +0.19 |
| 0.20–0.35 | 19 | 0.90 | 1.22 | +0.25 |
| 0.35–0.50 | 12 | 1.23 | 1.71 | +0.80 |
| >0.50 | 19 | 1.12 | 3.09 | **+1.37** |

**结论**：大气合成是一剂有效、且不会造成破坏的药（57 改善 / 0 恶化 / 轮廓零改动），但它的**效力上限由背景是否具备真实纵深结构决定**（ρ=+0.53），而不是由参数决定（σ 12→30 只 +0.05）。修不回来的 14 张倒挂卡，正是 `far≈0` 的平铺纹理背景——例如 shang-yachou-yue（0.25 → 0.27）、shang-wang-hai（0.40 → 0.41）、shang-pan-geng（0.64 → 0.66）。

这与第三、四节是同一个根因的两面：**深度信号在这类背景上既不能用于结构决策（层序），也不能提供足够的外观线索（景深）——因为那里本来就没有纵深。**

## 十、局限

- 阳性样本恒为 0，本实验只能测假阳性，测不出召回；任何「修好了」的说法在本设定下无法被验证——这本身就是结论的一部分。
- spread 与误裁率是相关关系，机制解释有代码依据，但未做「用真实平面模型 + 自适应阈值」的独立验证。
- 64 张卡均来自本仓库单一生产管线，风格分布集中（殷商 29 / 哈兰德 15 / VC 15 / 其他 5），外部有效性不宜说满。
- SR 是锐度比，不是人眼感知度量；「SR 高 = 层级更清楚」目前是**代理指标，未经主观实验校准**。这是后续最该补的一环。
- **已发现 SR 不能当「可见改善」的证据**：构造主观实验刺激时逐对测了背景区像素平均绝对差，它与 ΔSR 脱钩（刺激集内 ρ=+0.45, p=0.079）。极端例子：`shang-zhen-ren` ΔSR 全库最高 +7.76，但像素变化仅 3.5；`haaland-majin-buu` ΔSR 仅 +0.02，像素变化却有 6.2。说明 SR 可以在画面几乎没变时大幅提升——**「57/64 改善」应理解为「锐度统计量改善」，不是「看起来更好」**。这一条必须在正文里如实限定，否则就是过度声称。
- 大气合成未做主观偏好测试；57/64 改善只说明客观锐度分离变好，不等于观感更好。
- **参数灵敏度在两端都不显著**：σ 12→30 只多带来 +0.05 的 SR 中位提升（第 9 节）；反向把强度降到 σ9 / haze 0.06，在两张代表卡上实测几乎不可辨——`haaland-wanglaoji` 全图锐度 595→596、可见差异像素 7.6%，`shang-tang` 664→665、2.7%，而轻参数反而让商汤的远山层次变浅。两端都不动说明：**效果强度由 `far`（内容本身有无纵深）决定，不由参数决定**，因此也不存在「按题材调一套参数」这条出路。
