# HoloLab Studio · AI 生成 Prompt 最佳实践指南

> 目标：用更精准的 prompt 让 Seedream 一次生成到位，减少重生成率，节省时间和 API 费用。
> 核心理念：**告诉 AI 你要什么，更要告诉 AI 你不要什么。**

---

## 一、为什么精准 prompt 很重要

| 不够精准的 prompt | 更精准的 prompt |
|---|---|
| "里斯本老城区街道" | "里斯本老城区街道，葡式建筑，黄昏暖色调，**背景中绝对不出现任何电车、车辆、人物**，画面下方 40% 区域保持留白" |
| "日裔美国男性，科幻风格" | "日裔美国男性，科幻风格，暗金配色，**画面中绝对不出现任何文字、字母、数字、标志、铭牌**，人物居中占画面 65%，四周留白" |

不够精准的后果：AI 会"自由发挥"，画出你不想要的东西（文字、多余人物、车辆等），导致重生成。每次重生成 = 多等 15-30 秒 + 多花 0.12 元 + 多一次人工目检。

## 二、主体图 prompt 五要素

写 `subject_desc` 时，必须包含以下五个要素：

### 1. 外观描述（越具体越好）
- 人物：性别、年龄段、发型、发色、肤色、服装、配饰、表情、姿态
- 物体：形状、颜色、材质、角度、细节
- ✅ 好："30 岁日裔男性，黑色短发，胡茬，暗金色科幻战斗服，左肩有能量护盾发生器，面带自信微笑，身体微侧"
- ❌ 坏："一个男人"

### 2. 构图与比例
- 明确主体在画面中的位置和大小
- ✅ 好："人物居中，占画面 65%，半身像，头顶距画面顶部 10%，四周均匀留白"
- ❌ 坏：（不写，AI 随机构图）

### 3. 光线与氛围
- 明确光源方向、色温、戏剧化程度
- ✅ 好："侧逆光，暖金色主光 + 冷蓝紫色补光，边缘发光轮廓，电影级光影"
- ❌ 坏：（不写，AI 默认平光）

### 4. 负面提示（最重要！）
- **明确列出绝对不出现的东西**，这是减少重生成的关键
- 必加项：`绝对不出现任何文字、字母、数字、标志、铭牌、水印`
- 根据场景加：`绝对不出现其他人物` / `绝对不出现车辆` / `绝对不出现建筑` 等
- ✅ 好："画面中绝对不出现任何文字、字母、数字、标志、铭牌、水印，绝对不出现其他人物"
- ❌ 坏：（不写，AI 可能乱画文字）

### 5. 风格与质感
- 明确绘画风格、材质质感、配色体系
- ✅ 好："铜版画蚀刻质感混合赛博朋克光效，暗金与冷蓝紫配色，矿物颜料质感，笔触清晰"
- ❌ 坏："好看的风格"

## 三、背景图 prompt 四要素

写 `background_desc` 时，必须包含以下四个要素：

### 1. 场景描述
- 明确环境、地点、时间、天气
- ✅ 好："阿根廷纪念碑球场夜景，绿茵场中央，远处看台灯光璀璨，夜空有烟花"
- ❌ 坏："足球场"

### 2. 色调与氛围
- 明确主色调、情绪、光线
- ✅ 好："深蓝夜空 + 金色灯光，庆典氛围，薄雾弥漫，灯光有光晕效果"
- ❌ 坏：（不写）

### 3. 留白区域（非常重要！）
- 明确画面哪个区域要保持空白/简洁，因为文字层会叠在上面
- 通常要求画面下方 30-40% 区域保持安静
- ✅ 好："画面下方 40% 区域保持简洁的草地纹理，不出现任何复杂元素，供文字排版"
- ❌ 坏：（不写，AI 可能在下方画满东西，文字层叠上去就乱了）

### 4. 负面提示
- 明确背景中**绝对不出现**的东西
- 必加项：`绝对不出现任何人物、主体、文字、标志`（背景是空镜，不能有主体）
- 根据场景加：`绝对不出现车辆` / `绝对不出现建筑` 等
- ✅ 好："背景中绝对不出现任何人物、球员、文字、标志、车辆，纯环境空镜"
- ❌ 坏：（不写，AI 可能在背景里画个人，和主体层冲突）

## 四、真实案例对比

### 案例 1：电车卡（eletrico-28-lisboa）

**❌ 第一次（不够精准，重生成）：**
> subject_desc: "黄色有轨电车，里斯本风格"
> background_desc: "里斯本老城区街道"

**问题：** 背景里 AI 画了一辆电车（因为你说"里斯本"，AI 自然想到电车），和主体层冲突。

**✅ 第二次（精准，一次通过）：**
> subject_desc: "黄色复古有轨电车，28 路，车身有 Carris 标志，正面视角，占画面 60%，居中，车灯发光，**画面中绝对不出现任何文字、字母、数字（除车身上已有的 28 和 Carris）、水印**，四周留白"
> background_desc: "里斯本老城区上坡街道，葡式彩色建筑，鹅卵石路面，黄昏暖金色阳光，**画面下方 40% 区域保持简洁的路面纹理，背景中绝对不出现任何电车、车辆、人物、文字、标志**，纯环境空镜"

## 五、常见问题排查表

| 问题 | 原因 | 解决方案 |
|---|---|---|
| 画面出现乱码文字 | 没加负面提示 | 加 `绝对不出现任何文字、字母、数字、标志、铭牌、水印` |
| 背景里出现人物/主体 | 背景没加"不出现人物" | background_desc 加 `绝对不出现任何人物、主体` |
| 主体太小/太大/偏位 | 没写构图比例 | 加 `居中，占画面 65%，四周留白` |
| 文字层叠上去看不清 | 背景没留空白区 | background_desc 加 `画面下方 40% 区域保持简洁` |
| 风格不统一 | 主体和背景用了不同风格描述 | 两者共享同一个 `style` 前缀（build_prompts 已自动处理） |
| 人物不像 | 外观描述太模糊 | 加具体的发型、服装、年龄、表情等细节 |
| 颜色不对 | 没明确配色 | 加明确的主色调 + 补色 |

## 六、快速检查清单

写完 `subject_desc` 和 `background_desc` 后，对照这个清单检查：

**subject_desc 检查：**
- [ ] 外观描述具体（发型/服装/表情/姿态）？
- [ ] 构图比例明确（居中/占比/留白）？
- [ ] 光线氛围明确？
- [ ] 有负面提示（绝对不出现文字/其他人物）？
- [ ] 风格质感明确？

**background_desc 检查：**
- [ ] 场景描述具体？
- [ ] 色调氛围明确？
- [ ] 有留白区域（下方 30-40%）？
- [ ] 有负面提示（绝对不出现人物/主体/文字）？

**全部通过 → 一次生成到位的概率 > 80%**

---

## 七、AI 生成后目检要点

生成后花 10 秒检查：
1. **主体层**：有没有乱码文字？人物/物体像不像？构图对不对？有没有多余元素？
2. **背景层**：有没有出现人物/主体？下方留白区够不够？色调和主体搭不搭？
3. **叠加预览**：主体和背景叠在一起会不会冲突？（可以用图片编辑工具快速叠一下看效果）

有问题 → 针对性修改 prompt 后重生成（不要全部重写，只改有问题的部分）。
