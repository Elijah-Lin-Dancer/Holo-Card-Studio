# AI 分层生成策略 · ai_generate.py

> 把「一句话」变成一张全息卡所需的四层素材。核心思想：**分而治之**——每一层
> 用最合适的工具，不让一个模型包办所有事。

## 1. 四层结构与工具分工

| 层 | 内容 | 工具 | 为什么 |
|---|---|---|---|
| 主体 | 透明底角色/物体 | Seedream 生成 → **rembg** 抠图 | 生成模型不出透明 PNG；rembg 的 u2net 在插画主体上抠图稳定 |
| 背景 | 环境空镜 | Seedream 独立生成 | 需要与主体**分离移动**（视差），必须独立成层 |
| 线稿 | 白底黑线轮廓 | **OpenCV** 从透明主体提取 | 保证与主体像素级注册，AI 重画无法对齐 |
| 文字 | 卡面标题/编号 | **字体渲染** | 生成模型画中文字形不可靠；精确排版可控 |

## 2. 提示词工程

### 2.1 共享风格前缀

主体与背景的提示词共享同一段风格描述，尽量收敛到同一视觉世界：

```
风格前缀 = "日式浮世绘与水墨动漫勾勒的收藏卡插画，矿物颜料质感，笔触清晰，戏剧化夜景灯光"
主体 prompt = 风格前缀 + 主体描述 + "构图：居中，占画布约65%，四周留呼吸空间"
背景 prompt = 风格前缀 + 环境描述 + "中下部40%留白供叠字，不出现人物"
```

### 2.2 参考图模式（以图生图）

用户上传照片（宠物/朋友/角色）时，把原图作为 `image` 字段传给 Seedream 5.0，
prompt 只描述风格与保留约束：

> "保留图中主体的姿态、构图与身份特征，重绘为【风格】插画"

Seedream 5.0 支持文本+图像联合输入，能锁定主体身份，这是选它的原因之一。

### 2.3 构图一致性的缓解

见 `docs/architecture.md §3.5`。核心：背景"安静留白" + 视差遮挡 + 诚实记录 tradeoff。

## 3. 抠图（rembg）

- 模型：`u2net`（~176MB，比默认 bria-rmbg-2.0 的 1GB 更适合 CPU 推理）；
- 流程：输入降采样到 1/2 → 推理 → 放大回原尺寸（LANCZOS）；
- 兜底：抠图失败时退化为"中心椭圆 alpha 渐变"，保证流水线至少能过校验
  （真实透明 + 可见像素），但视觉质量优先走正常路径。

## 4. 线稿提取（OpenCV）

```
1. alpha 通道阈值 → 主体区域 mask
2. Canny(彩色灰度)  → 内部细节边缘（服装纹理、五官）
3. Canny(alpha mask) → 主体轮廓线
4. 合并：内部边缘 ∩ mask ∪ 轮廓线 → 白底黑线
5. erode 一次加粗黑线（注意：dilate 会把细黑线抹成白色，这是踩过的坑）
```

要点：线稿与主体**共享同一画布和坐标**，天然对齐；阈值参数（55/150）对插画
风格主体效果稳定。

## 5. 文字层（generate_typography.py）

从 `card-config.json` 读取标题/副标题/收藏/招式/编号，用系统 CJK 字体
（Noto Serif CJK）在透明画布上精确排版，附金色分割线与描边。宽度自适应缩字，
防止长标题溢出。

## 6. 为什么这样设计

- **不迷信单一模型**：图像生成、抠图、边缘提取、文字渲染各用最合适的工具；
- **可靠性优先**：每层都有校验（validate_assets 检查真实 alpha、线稿极值），
  失败有兜底，流水线可复现；
- **可解释**：每层产物、参数、prompt 都落在磁盘，调试与学术审查都方便。
