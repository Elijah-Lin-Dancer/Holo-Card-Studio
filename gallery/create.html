想要真卡？复制命令，本地跑一遍

在线展厅是纯静态页面，不携带任何密钥。真实生成在本地完成：克隆仓库 → 一句话出卡 → 一键发布，全程约几分钟，管线完全开源可复现。

git clone https://github.com/xin-hao2003/Holo-Card-Studio.git cd Holo-Card-Studio python3 generator/scripts/one_shot_card.py "你的创意"
1 · 克隆仓库git clone 拉取全部管线源码与文档。
2 · 一句话出卡文字模型自动生成卡面配置、编号与渲染参数（需在 .env 配置豆包 API Key）。
3 · 一键发布压缩素材、渲染预览动画、更新清单，push 后 GitHub Actions 自动上线。

为什么不在网页里直接生成？一条完整的生成链需要调用豆包 API（密钥绝不能进入前端）并在本地跑 Blender 渲染。这是有意的架构取舍：展厅负责“看”，管线负责“造”，两者解耦后，任何人都能长期打开展厅，而创作者拥有全部控制权。管线原理见 README 与 docs/（架构、AI 管线、图形学、白皮书）。
