AI 四层素材分工

分层生成是这条管线最核心的设计：每一层只负责一类信息，让 3D 合成时拥有独立的景深与光照通道。

SUBJECT · 主体层

卡面主角，用于 3D 前置凸出，视差最明显；使用抠图工具分离前景。

BACKGROUND · 背景层

场景氛围，固定在后层，形成景深；随卡片翻转产生视差。

LINEART · 线稿层

轮廓与结构线，作为 3D 卡面的基础造型依据。

TEXT · 文字层

卡面标题、编号与签名，排版后独立成层，保证文字清晰。

技术栈

生成、渲染、交互、部署四个环节各选一个主力工具，整条链路公开可复现。

豆包 Seedream 5.0

四层素材的 AI 生成引擎，端到端调用，支持分层 prompt 控制。

Blender 4.5

3D 卡体建模与 Cycles 渲染，输出带四材质通道的 GLB。

Three.js

浏览器 WebGL 查看器：视差、镭射、翻面全部实时渲染。

Python 脚本管线

生成、合成、导出、发布全自动，一张新卡一条命令。

GitHub Actions + Pages

提交即部署，纯静态托管，全球可访问，零服务器成本。

Git / 版本控制

每张卡、每次改版都有提交记录，工程节奏可审计。

设计决策

  • 纯静态零后端——无数据库、无服务器，作品集可被任何人长期打开。
  • 分层生成——AI 只画素材，3D 结构由工程决定，稳定可复现。
  • 一键发布——从新卡到上线一条命令，清单与归档自动同步。
  • 共享依赖——多卡共用一份 Three.js 资产，展厅保持轻量。
